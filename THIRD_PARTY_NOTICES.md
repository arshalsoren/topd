## Theme names and colors

The app offers themes named after well-known editor color schemes: Dracula, Nord, One Dark,
GitHub Light, Ayu Light, and Gruvbox Light. These names are used only to identify the
look. The app does not contain any code, assets, or files from those projects. Its color
values were chosen to resemble each look and were not copied from any project's source.

Synthwave, Ember, Slate, and Ocean are original palettes.

Those project names are trademarks or project names of their owners. Their use here
identifies a color look and does not imply endorsement by those projects.

## SF Symbols

Menu bar and popover icons are SF Symbols, drawn by macOS at run time. The symbol artwork is
not included in this repository. See Apple's SF Symbols license for how the symbols may be
used.

The topd logo and app icon are original artwork drawn in code (`Sources/topd/Logo.swift`)
and as `Support/AppIcon.icns`.
